Folder buttons (EPG logo dashboard)

The folder button next to each channel shows that page selected in YOUR copy of this
project's raw folder, so you can rename it or edit the HTML.

One-time setup on each computer (each person runs it from their own copy):
  Windows: double-click install-windows.cmd   (undo: uninstall-windows.cmd)
  Mac:     double-click install-mac.command   (or: bash install-mac.command)
  Linux:   bash install-linux.sh

Keep this folder at tools/folder-button inside the project; it finds raw/ from there.
If you move the project, run the setup again.
